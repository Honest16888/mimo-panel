# 06 · 桌面版

## 形态

`node server.js` 起一个只监听 `127.0.0.1` 的本地服务，浏览器打开 `http://127.0.0.1:8787`：

```
┌─────────────────────────────┐
│ 浏览器  http://127.0.0.1:8787 │
│   ├─ GET /            index.html
│   └─ GET /api/fetch?url=&key=  ──►  Node https ──► 各家 OpenAPI
└─────────────────────────────┘
```

为什么不是 Electron：Electron 要额外打包一份 Chromium（一百多 MB），而本项目需要的只是
"同源 + 能发跨域请求"，一个静态服务 + 转发接口就够，零依赖、跨平台、`node server.js` 起步。

## 页面差异

页面与安卓端同源，通过一行判断切换请求实现：

```js
var DESKTOP = (typeof window.MimoNative === "undefined");
```

| 能力 | 安卓 | 桌面 |
|---|---|---|
| 请求 | `window.MimoNative.get(url, key)` | `fetch("/api/fetch?url=&key=")` |
| 顶部留白 | `--sat`（状态栏） | 无 |
| 布局 | 手机单列 | 1080px 居中，宽屏概览四列 |
| APK 专属项 | 底部留白、布局诊断、添加到桌面 | 自动隐藏 |
| 演示 | 设置里"演示数据"开关 | 额外支持 `?mock=1` |
| 预警 / 小组件 | 原生 AlarmManager + AppWidget | 无（不做浏览器通知，避免误报） |

## 本地服务的三个接口

| 路径 | 说明 |
|---|---|
| `GET /api/fetch?url=&key=` | GET 转发。必带 `Authorization: Bearer` + `api-key`，20 秒超时，`Cache-Control: no-store` |
| `GET /api/meta` | 自检：版本、监听地址 |
| `GET /api/fetch?...&mock=1` | 按目标域名返回演示 JSON，用于无 Key 预览 |

安全设计：

- 只监听 `127.0.0.1`，局域网内其他设备访问不到
- 只允许 `http/https`，其余协议直接 400
- 转发是 GET-only，不落盘、不打印 Key
- 静态文件路径做了 `startsWith(ROOT)` 校验，避免 `../` 穿越
- 端口可用 `PORT=xxxx node server.js` 覆盖

## 使用

```bash
cd desktop
node server.js                 # 正常模式
# 无 Key 想先看界面：浏览器打开 http://127.0.0.1:8787/?mock=1
```

设置里选供应商 → 填 Key → 保存；想同时看 MiMo 和 DeepSeek，点「新增账号」再配一个，
顶部标签一键切换。

## 已知边界

- 余额型厂商（DeepSeek / Kimi / 硅基 / OpenRouter）同样只有余额接口，用量走余额快照推算
- 桌面端不做后台常驻，快照只在页面打开并刷新时记录；想更准可以挂着页面定时刷新
- 自定义接口会把请求发到你填的任意地址，请自行确认来源可信
