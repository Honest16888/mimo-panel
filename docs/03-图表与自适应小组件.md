# 03 · 图表渲染与自适应小组件

## Canvas 自绘：不引第三方图表库

页面只有一个 HTML 文件，图表全部用原生 Canvas 2D 手绘，好处是体积小、渲染可控，代价是要自己处理 DPI 与重排。

### 踩过的坑：Canvas 高度指数膨胀

最初图表的做法是每次重绘都根据"当前宽度"反算高度并写回属性：

```js
cv.height = cv.width * ratio;   // ❌ 每次 setAttribute 都会触发一次重新布局
```

`canvas.width/height` 属性一旦改写，浏览器会把画布重置并清空；下一帧读到的 `clientWidth` 又变了，
于是每一帧都放大一点，几帧后画布高度变成天文数字，整块图表变成空白。

**修复**：把基准高度只读缓存一次，之后只用 CSS 控制显示高度：

```js
if(!cv.__baseH) cv.__baseH = cv.getAttribute("height");
// 重绘时：只在容器尺寸真的变化时重算，并用 __baseH 作为基准
```

另外加了两道保险：

- 布局尚未完成（`clientWidth === 0`）时直接跳过绘制，并 `scheduleRepaint()` 下一帧再试
- `scheduleRepaint` 用 260ms 防抖 + RAF，避免 resize 风暴里疯狂重绘

DPI 处理：`canvas.width = cssWidth * devicePixelRatio`，再 `ctx.scale(dpr, dpr)`，
这样 3.25 密度的手机上线条和文字不会糊。

### 堆叠柱图（每日消费构成）

`drawStacked(canvas, cats, stacks, opt)`：

- 四条序列：输入未命中（橙）、输入命中（浅橙）、输出（黄）、插件（灰）
- 纵轴刻度用"好看的数字"（1/2/5×10ⁿ）取整，四等分
- 柱子宽度 = 槽宽 × 0.62，上限 26px，圆角取 `min(3, 高度/2, 宽度/2)`
- X 轴标签按天数自动稀疏（≤8 天全显示，≤15 天隔 1，再多则按 `ceil(n/8)`）
- 没有数据时画"暂无数据"，不画空坐标系

### 多模型对比（多折线）

`drawMulti(canvas, cats, series, opt)`：

- 先按区间总量排序取前 6 个模型，避免二十条线糊成一团
- 颜色固定成一条色板（橙 → 黄 → 绿 → 蓝 → 紫），同一模型每次都是同一个颜色
- 支持"消费 / Token"两个口径切换：切换只改取数函数，不改绘图
- 图例可点，点一下隐藏该线（中间那条被两条线夹住时很好用），全隐藏时画"已全部隐藏，点图例可恢复"
- 末点画一个小圆点，方便看清最后一天的落点

### 演示数据

没有 Key 时页面内置一套模拟数据（三条模型线、两条 Key、每日插件消耗），
用来验证渲染和布局而不打真实接口。桌面版还有 `?mock=1`，由本地服务返回演示 JSON。

## 安卓桌面小组件

### 三套排布自动切换

`res/layout/widget_mimo.xml` 里放了三个容器：

| 容器 | 触发条件 | 内容 |
|---|---|---|
| `box_wide` | 宽 ≥ 205dp 且明显扁（宽高比大） | 左余额 + 今日/日均，右 14 天折线 |
| `box_square` | 其余中等尺寸 | 余额在上，走势图铺满下半区 |
| `box_mini` | 宽 < 115dp 或高 < 75dp | 只有大号余额 + 可撑天数 |

`AppWidgetProvider.onAppWidgetOptionsChanged()` 里读取
`OPTION_APPWIDGET_MIN_WIDTH / MAX_WIDTH / MIN_HEIGHT / MAX_HEIGHT`，
判断后只显示一个容器，其余 `GONE`；尺寸一变立刻按缓存重排，**不联网**。

### 折线位图

RemoteViews 不能放 Canvas，所以趋势图是**在 `onUpdate` 里用 `Bitmap` + `Canvas` 画好再 `setImageViewBitmap`**：

- 位图尺寸按小组件的实际像素宽高生成，所以拉长拉扁都不会变形
- 数据来自本地缓存的最近 14 天余额/消费，尺寸变化时直接用缓存重画，不打接口
- `updatePeriodMillis` 设 30 分钟兜底；真正的实时刷新靠主页刷新时顺带写缓存

### 为什么桌面列表搜不到

早期 `widget_mimo_info.xml` 缺 `previewLayout` 与 `description`，部分 ROM 的"添加小组件"搜索面板会直接不显示。
补上之后仍有搜不到的情况，于是再加一层**一键添加**：
`AppWidgetManager.requestPinAppWidget()`（Android 8+），点按钮直接弹系统确认框把小组件钉到桌面，
绕开各家 ROM 对小组件列表的改造。

## 限额与自检

- 手动刷新最短间隔 20 秒；自动刷新下限 60 秒
- 命中 429 进入 45 秒冷却，展示旧数据并倒计时自动重试
- 设置里保留一块"布局诊断"，输出 `insetTop / insetBottom / density / screenH / webH / padBottom`
  这几个数字，是排查底部黑边时唯一可靠的信息源
